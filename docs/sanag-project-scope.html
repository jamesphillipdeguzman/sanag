1. Project Overview

SANAG (Satellite Analytics for Nightlight & Assessment Grid) is a satellite-based disaster and power-recovery dashboard focused on Panay Island, covering the four provinces of Aklan, Antique, Capiz, and Iloilo.

The system uses freely available NASA VIIRS nighttime-light satellite data to analyze changes in nighttime brightness before, during, and after a disaster or major power disruption. The ultimate goal is to provide an understandable, data-driven way to examine how quickly municipalities bounce back from widespread infrastructure failures.

Core Concept: Satellite Data → Data Processing → Recovery Calculation → Database → API → Map & Charts → AI Explanation

4. Scientific Recovery Formula

Mathematical Definition:
Recovery Ratio = Post-Event Light ÷ Baseline Light

Example: If a municipality normally registers a nighttime radiance value of 100 and falls to 80 post-disaster:
Recovery Ratio = 80 ÷ 100 = 0.80 (80% of normal baseline).

Important Architecture Rule: The application backend calculates all scientific metrics. Gemini only explains the results in plain text. Gemini must never be used to compute or derive numerical Recovery Ratios.

8. Glossary of Terms

Term Definition
Choropleth Map A thematic map in which geographical areas are shaded or patterned in proportion to a statistical variable (e.g., Red/Yellow/Green to represent recovery status).
DNB (Day/Night Band) A highly sensitive sensor on the VIIRS satellite that measures raw optical radiance (photons) rather than standard RGB color pixels.
Concrete Example: Unlike a standard camera that captures a white pixel for a glowing streetlamp, the DNB measures the actual physical energy and intensity of the light emitted by that streetlamp.
GeoJSON An open standard format designed for representing simple geographical features, along with their non-spatial attributes, using JavaScript Object Notation. Used to draw the Panay municipal boundaries.
Google Earth Engine (GEE) A cloud-based geospatial processing platform that allows developers to run algorithms on petabytes of satellite imagery without downloading massive files locally.
LGU Local Government Unit. The foundational administrative divisions in the Philippines (provinces, cities, municipalities, and barangays).
Radiance The scientific measurement of the amount of light emitted or reflected by a specific area, captured by the satellite's sensors.
Recovery Ratio (R(t)) The calculated mathematical metric defined as the post-event radiance divided by the baseline (normal) radiance.
VCMSLCFG Stands for VIIRS Cloud Mask Stray Light Corrected. It is the NASA/NOAA monthly nighttime lights composite dataset used in this project to establish the "normal" baseline light levels before a disaster hits.
VIIRS Visible Infrared Imaging Radiometer Suite. A sensor aboard the Suomi NPP and NOAA-20 weather satellites that detects nighttime lights and tracks power outages.
VNP46A2 Stands for VIIRS/NPP Product 46A2 (Daily Nighttime Lights). The specific NASA Earth observation dataset providing daily, lunar-adjusted, cloud-masked nighttime light metrics at a 500-meter resolution used to track day-to-day power dips and recovery.
Zonal Statistics The process of calculating aggregate values (such as averages) for data pixels that fall within a specific geographic boundary.
Concrete Example: Taking all the individual radiance measurements inside the map boundary for Iloilo City and averaging them together to determine the city's overall light level for the night.
